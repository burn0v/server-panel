Условия использования API

Используйте ключ честно и в рамках лимитов сервиса.

1. Суточный лимит

Максимум {{ daily_limit }} запросов в сутки. Лимит обновляется каждые 24 часа.

2. Лимиты запросов

Не делайте больше 100 запросов в минуту. В случае превышения доступа может быть временно ограничен.

3. Ответственное использование

Не используйте ключ для автоматического спама, тестовых «душ» или других вредоносных сценариев.

4. Безопасность

Храните ключ в секрете. Не публикуйте его в открытом коде или репозиториях.

5. Отзыв доступа

Администрация оставляет за собой право отозвать ключ в любой момент при нарушении правил.
